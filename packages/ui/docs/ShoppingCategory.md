# ShoppingCategory

Category heading in a shopping list — Produce, Proteins, Grains & Pantry — in stamp red over a red rule.

```jsx
<ShoppingCategory>Produce</ShoppingCategory>
<ShoppingRow>Spinach, 2 bunches — $4.50</ShoppingRow>
```

The red rule echoes the index card's own margin line, so a categorised list looks written onto the same stationery rather than laid over it.

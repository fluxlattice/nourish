# WelcomeGreeting

The small script salutation immediately above a `StepTitle` on the welcome card.

```jsx
<WelcomeGreeting>Hello,</WelcomeGreeting>
<StepTitle>Welcome to Nourish</StepTitle>
```

Tucked tight against the title with negative margin so the two read as one handwritten phrase — don't put anything between them.

One word or two. It's a greeting, not a line of copy.

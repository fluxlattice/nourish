# StepTitle

The handwritten card title, 42px Dancing Script in dark ink.

```jsx
<StepTitle>Your goal &amp; activity</StepTitle>
<StepSub>We'll tailor your entire plan around this.</StepSub>
```

Pair it with `StepSub` for the question-and-explanation pattern every step uses: the title asks, the sub says why.

**Keep it short** — three or four words. The script face is expressive at 42px and a long title wraps into an unreadable tangle. Defaults to `h2` because `Brand` owns the page `h1`.

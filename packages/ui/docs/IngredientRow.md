# IngredientRow

One ingredient, preceded by a small hand-drawn checkbox tilted a few degrees.

```jsx
<RecipeSectionTitle tone="ingredients">Ingredients</RecipeSectionTitle>
<IngredientRow>1/2 cup rolled oats</IngredientRow>
<IngredientRow>1 tbsp chia seeds</IngredientRow>
```

The box is decorative — nothing ticks it. It signals "a list you work through" without pretending to be interactive state the app doesn't keep.

For shopping entries use `ShoppingRow`, which tilts the other way.

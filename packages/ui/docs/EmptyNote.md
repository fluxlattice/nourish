# EmptyNote

Quiet placeholder for a section with nothing to show.

```jsx
<EmptyNote>Generate a new plan to see recipes here.</EmptyNote>
```

Says what is missing and how to get it, on the same dashed cardstock as everything else.

Never uses the `ErrorNote` treatment — empty is a normal state, and dressing it as a failure makes the app look broken.

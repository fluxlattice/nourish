# DayHeading

Small uppercase caption naming the day above a list of meals.

```jsx
<DayHeading>Day 3</DayHeading>
<MealRow type="Breakfast" photo={<Polaroid type="breakfast" />}>
  Greek yogurt parfait with berries and granola (380 cal)
</MealRow>
```

Sits inside the card, under the `Segmented` strip. It restates which day is showing so the card is readable on its own once the tabs scroll out of view.
